# Inventory Monitoring

App d'inventaire et de profit pour vendeur de cartes Pokémon (VannzTCG).

**Ouvrir l'app :** https://vannztcg.github.io/Inventory-Monitoring/

## Installer sur iPhone
1. Ouvre l'adresse ci-dessus dans **Safari**.
2. Touche **Partager** → **Sur l'écran d'accueil** → **Ajouter**.

## Données
Tes cartes, ventes et dépenses restent **seulement sur ton appareil** (rien n'est envoyé dans ce dépôt).
Fais une sauvegarde régulière : Réglages → Données → **Sauvegarde complète (fichier)**.
Pour restaurer ou transférer : Réglages → Données → **Importer un fichier**.
